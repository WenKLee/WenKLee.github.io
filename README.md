# Wenke Li

**Computer Vision · Multimodal Learning · Remote Sensing**

Information Engineering University · Zhengzhou, China

[ORCID](https://orcid.org/0009-0004-7285-3026) · [Scopus](https://www.scopus.com/authid/detail.uri?authorId=59654678400)

My work spans multimodal semantic segmentation, point cloud understanding, video super-resolution, and remote sensing image restoration.

## Research interests

- **Multimodal perception:** LiDAR–camera fusion and RGB–thermal semantic segmentation.
- **3D scene understanding:** Point cloud semantic segmentation and oversegmentation.
- **Video super-resolution:** Satellite and UAV video enhancement, arbitrary-scale reconstruction.
- **Image restoration:** Diffusion models and shadow removal for remote sensing imagery.
